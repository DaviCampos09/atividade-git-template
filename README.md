# 🚀 Curso de Git e GitHub — DataLab

Repositório destinado aos estudos, exercícios e práticas desenvolvidos durante o curso de Git e GitHub, realizado pelo DataLab.

## 📚 Sobre o curso

O curso tem como objetivo apresentar os principais conceitos de controle de versão utilizando Git e GitHub, desde os comandos básicos até o gerenciamento de repositórios e a colaboração em projetos.

## 🎯 Conteúdos abordados
- Introdução ao Git e ao GitHub
- Instalação e configuração do Git
- Criação e inicialização de repositórios
- Comandos básicos do Git
- Controle de alterações e histórico de versões
- Criação e gerenciamento de branches
- Commits e boas práticas de versionamento
- Conexão entre repositórios locais e remotos
- Envio e atualização de arquivos com push e pull
- Clonagem de repositórios com clone
- Colaboração em projetos utilizando GitHub
## 🛠️ Tecnologias e ferramentas
- Git: sistema de controle de versão distribuído.
- GitHub: plataforma de hospedagem e colaboração em repositórios Git.
- Terminal: utilizado para executar comandos e gerenciar repositórios.
## 💻 Principais comandos do Git
#### |Comando - Descrição|
- git init	- Inicializa um repositório Git
- git status - Verifica o estado dos arquivos
- git add . - Adiciona alterações à área de preparação
- git commit -m "mensagem"	- Registra as alterações
- git log - Exibe o histórico de commits
- git branch - Lista as branches
- git switch - Troca de branch
- git clone	- Clona um repositório remoto
- git push - Envia alterações para o repositório remoto
- git pull - Busca e integra alterações do repositório remoto

## 📈 Objetivos
- Compreender os fundamentos do controle de versão.
- Utilizar os principais comandos do Git.
- Criar e gerenciar repositórios no GitHub.
- Acompanhar alterações e versões de arquivos.
- Desenvolver habilidades de colaboração em projetos.
